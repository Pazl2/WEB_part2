# EuroTruck Forum — Практическое занятие №1 (Middleware и шаблонизаторы)

Ветка репозитория: `pz21`

Express-приложение с форумом дальнобойщиков: JSON API (`/posts`, `/auth`) с базой данных PostgreSQL и HTML-страницы на EJS, данные которых хранятся в массиве в памяти.

## Запуск

1. Установить зависимости:

```bash
npm install
```

2. Создать файл `.env` по образцу `.env.example`:

```
JWT_SECRET=ваш_секрет
JWT_EXPIRES_IN=1h
```

3. Настроить подключение к PostgreSQL в `config/config.json` (пользователь, пароль, база `eurotruck_db`) и создать базу данных.

4. Применить миграции и сидеры (нужны только для JSON API):

```bash
npx sequelize-cli db:migrate
npx sequelize-cli db:seed:all
```

5. Запустить сервер:

```bash
npm start
```

Для запуска с автоперезагрузкой: `npm run dev`.

Сервер доступен по адресу http://localhost:3000.

## Страницы (EJS)

| Адрес | Описание |
|-------|----------|
| `GET /` | Список тем |
| `GET /item/:id` | Детальная страница темы |
| `GET /add?auth=1` | Форма добавления темы (требует авторизацию) |
| `POST /add?auth=1` | Добавление темы в массив, редирект на главную |
| `GET /login` | Страница, на которую перенаправляются неавторизованные пользователи |
| `GET /error-test` | Намеренно вызывает ошибку для проверки страницы 500 |
| любой другой адрес | Страница 404 |

Авторизация имитируется: доступ к `/add` открыт только при наличии query-параметра `?auth=1`.

## Middleware

- `middleware/requestLogger.js` — логирует метод, URL и время запроса.
- `middleware/mockAuth.js` — имитация проверки авторизации.
- `middleware/errorHandlers.js` — обработчики ошибок 404 и 500.

## Логи

Логи пишутся в консоль и в файл `logs/server.log` (папка создаётся автоматически, в git не попадает).

## JSON API

Маршруты `/posts` и `/auth` (JWT, двухфакторный код) работают с базой данных и не затронуты новыми страницами.
